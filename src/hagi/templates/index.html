macOS & Local Network / CORS Setup

If Anki is open but connection fails, AnkiConnect needs to permit requests from this page origin ():

  1. In Anki, open Tools → Add-ons → AnkiConnect → Config.
  2. Add your origin to webCorsOriginList:
"webCorsOriginList": [
  "http://localhost",
  "http://127.0.0.1",
  "*"
]
